# Student Finance Tracker

## Overview

Student Finance Tracker is a web application designed to help students manage their personal finances. It provides an interface for recording income and expenses, reviewing financial summaries, and understanding spending habits.

## Features

* Dashboard for reviewing financial activity.
* Recording income and expenses.
* Summary of total income, expenses, and balance.
* Organizing transactions by category.
* Browser-based interface.

## Technologies Used

* **HTML5** — Structures the application.
* **CSS3** — Styles the interface.
* **JavaScript** — Handles application logic and user interactions.

## Getting Started

### Prerequisites

A modern web browser, such as Google Chrome, Firefox, or Safari.

### Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
